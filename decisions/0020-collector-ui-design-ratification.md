## Recommendation

RATIFY AS WRITTEN (operator review of the M40 proposal and M41 adversarial
editorial corrections confirmed the proposal is structurally sound, with
no unresolved normative defects).

## Operator ruling

The operator approved the M40 proposal (31f8bba) and the M40 amendment
(e777384) addressing three normative/implementation boundary corrections:
byte-identity demoted from normative MUST to reference implementation
evidence; accent-only override demoted from normative MUST to reference
implementation evidence with domain-specific adaptations permitted; and
GUI collection applicability correctly scoped to products whose intended
workflow includes it. The M41 adversarial review applied six editorial
corrections (commit 95fa2de) and found no structural or normative defects.
The operator then authorised ratification.

## Scope

Ratification covers STD-CUD-001 only. It does not admit conformance for
any of the six collector Clanks; a separate admission mission is required.
It does not merge with existing UI, data, operations, or deployment domains.

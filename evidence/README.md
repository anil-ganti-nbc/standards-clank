# Evidence

Standards Clank stores evidence *references*, not duplicated history. Do
not copy entire Diagnostic Clank ledgers or incident write-ups into this
directory.

If a reference needs more context than fits in a standard's `evidence[]`
array (see
[../schemas/evidence-reference.schema.json](../schemas/evidence-reference.schema.json)),
a short pointer file may live here — a summary and a link/path back to the
source system (Diagnostic Clank, an operator conversation, a specific
Clank's incident log), not a copy of it.

Empty for now; populated as real standards are proposed with supporting
evidence.
